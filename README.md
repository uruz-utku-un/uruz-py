# Uruz-Py

Uruz-Py, günlük geliştirme süreçlerini hızlandırmak amacıyla geliştirilen Python yardımcı araçları koleksiyonudur.

Bu proje; performans testleri, benzersiz kimlik üretimi ve birim test süreçlerini kolaylaştıran modülleri tek bir çatı altında toplamayı hedeflemektedir.

> ⚠️ Bu proje aktif geliştirme aşamasındadır. API yapıları, modül isimleri ve kullanım şekilleri yayın öncesi süreçte değişebilir.

---

## Modüller

### Uruz Benchmark Tester

Kod parçalarının performansını ölçmek ve karşılaştırmak amacıyla geliştirilen benchmark aracıdır.

Özellikler:

- Fonksiyon performans ölçümü
- Karşılaştırmalı benchmark testleri
- Tekrarlı ölçüm desteği
- Sonuç raporlama araçları

---

### Uruz ID Generator

Çeşitli senaryolar için benzersiz kimlikler üretmeyi amaçlayan araçtır.

Özellikler:

- Rastgele ID üretimi
- Özelleştirilebilir uzunluk
- Prefix ve suffix desteği
- Proje içi kullanım için hafif yapı

---

### Uruz Unit Tester

Python projeleri için basit ve anlaşılır test süreçleri oluşturmayı amaçlayan test aracıdır.

Özellikler:

- Test çalıştırma
- Test raporlama
- Başarılı/başarısız sonuç analizi
- Genişletilebilir yapı

---
